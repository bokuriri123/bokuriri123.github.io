ISCTF2025 Web/ezpop

题目：ISCTF2025 Web/ezpop
考点：pop 链 + PHP 原生类利用

一些魔术方法

魔术方法 触发时机 常见危险操作
__construct() new 时 初始化
__destruct() 对象销毁（引用计数归零 / 脚本结束时） 几乎必被触发，POP 链的天然入口
__toString() 对象被当字符串用：echo $obj、$a . $obj、"$obj"、strlen($obj)、与字符串比较 拼接、输出
__invoke() 对象被当函数调：$obj()、call_user_func($obj)、array_map($obj,...) 命令执行
__get() 读不存在/不可访问的属性：$obj->noSuchProp $this->x->y(...) 继续跳
__set() 给不存在/不可访问属性赋值 二次注入
__isset() / __unset() isset($obj->p) / unset($obj->p)
__call() 调用不存在的方法：$obj->noMethod() 中转
__callStatic() 调用不存在的静态方法
__sleep() serialize() 时
__wakeup() unserialize() 时（注意：在反序列化阶段就执行） 历史上常用 C: 序列化或改属性个数绕过
__unserialize() / __serialize() PHP 7.4+ 的新序列化协议
__clone() clone 时
__debugInfo() var_dump() 时

最重要的一条：unserialize() 不会调用 __construct（构造函数被跳过），但对象一旦被创建成功，脚本结束时就一定会被销毁 → __destruct 必然执行。

所以题目里 __destruct 一般都是链子的入口，__construct 里的校验通常是”写了但不生效”的假防守。

POP 链

1 找链的方法：

每一条跳都是同一个模式：

代码里把某个属性 以某种方式使用 → 那个属性对应的位置上，你放的是一个对象 → PHP 自动触发该对象的某个魔术方法。

代码里的写法 触发的魔术方法
echo $this->x; / $s = "a".$this->x; x::__toString
$f = $this->x; $f(); / call_user_func($this->x) x::__invoke
$this->x->y;（y 属性不存在） x::__get
$this->x->y();（y 方法不存在） x::__call
$this->x->y = 1;（外部赋不可见属性） x::__set
new $this->x(...) / new $class(...)（$class 可控） 任意类的构造 → 原生类 gadget

2 常见组合套路

原生类 gadget

“原生类”= PHP 内置的类（SplFileObject、DirectoryIterator、SoapClient……）。它们不需要你在题目里 new 出来，链子能 new 任意类 就能直接借来用。

本题的借法藏在 eenndd::__get：

array_walk($this, callback) 的隐藏行为

array_walk 的第一个参数 可以是对象，此时 PHP 会把对象的属性当数组遍历，回调收到：

  • $day1 = 属性值
  • $day2 = 属性名

实测（PHP 8.1）：

于是 new $day2($day1) 就等于 new SplFileObject('/tmp/myflag')，foreach 遍历 SplFileObject 会逐行读出文件内容并 echo 出来。

取巧点：反序列化时属性名不受 $ 声明限制，可以塞任意名字，所以属性名可以是任意类名。

链的推演

对象图:

  • begin #1 的 __destruct 里 echo $var1 → var1 放 begin #2 对象 → 触发 begin #2::__toString
  • begin #2::__toString 里 $newFunc = $var2; return $newFunc() → var2 放 flaag 对象 → 触发 flaag::__invoke
  • flaag::__invoke 过闸门后 $this->var10->hey → var10 放 eenndd，hey 属性不存在 → 触发 eenndd::__get

通用解题（）

  1. grep 全部 function __，把每个魔术方法抄出来，标上”触发条件”
  2. 找入口：__destruct / __wakeup / __toString（能由”外部对象当字符串用”触发）
  3. 找终点：system / exec / eval / include / file_get_contents / fopen / unserialize / new
  4. 每看一处 $this->x，问一句：”这行是把 x 当字符串、当函数、当属性、还是当类名用的？”——这一行就是下一跳
  5. new $var(...)、array_walk($this,...)、call_user_func($this->x)、$$var 都是动态调用，优先怀疑
  6. 用 PHP 生成 payload（serialize() + urlencode()），不手写长度
  7. 先在本机同版本 PHP 上验证（php -r 或 php -S），再打靶场
  8. 遇到 == 闸门先算 PHP 版本；md5(md5()) == 数字、"0e..." == "0e..." 都是松散比较的经典坑
