关于渗透测试

渗透测试入门笔记 - 信息收集篇

一、 基础指纹识别

在拿到目标后，第一步通常是识别目标的基本架构，做到“看菜下饭”。

  • 操作系统：判断是 Windows 还是 Linux，影响后续提权方式和 Payload 的选择。
  • 中间件：查看 HTTP 响应头中的 Server 字段，如：
    • Server: Apache
    • Server: nginx/1.18.0
    • 后续动作：根据组件版本去查对应的 Nday（公开漏洞）或 CVE 漏洞。
  • 脚本信息：判断是 PHP、Java、Python 还是 Node.js，决定后续找哪类漏洞（比如 Java 找反序列化，PHP 找文件包含）。
  • 源代码：获取源码后可以进行白盒代码审计，挖掘 0day。
  • 数据库信息：判断数据库类型（MySQL、MSSQL、Redis等），为后续 SQL 注入或未授权访问做准备。

二、 域名信息收集

这是信息收集的重中之重，用于资产测绘和扩大攻击面。

1. Whois 查询

  • 内容：域名注册人、邮箱、注册时间、过期时间。
  • 作用：用于社工钓鱼，或寻找注册时间久远但疏于维护的老资产。
  • 常用工具：whois 命令、站长工具。

2. DNS 记录

  • A记录：域名对应的 IP 地址。
  • CNAME记录：别名记录，常用于 CDN 识别。
  • 作用：了解目标的网络拓扑，定位真实服务器。

3. 子域名收集

  • 手段：证书透明日志（Certificate Transparency）、字典爆破工具。
  • 常用工具：OneForAll、subfinder、Layer 等。
  • 意义：主站防御严密，边缘子域名往往是突破口（比如 test.xxx.com 或 dev.xxx.com）。

4. 真实 IP（绕过 CDN）

  • CDN（内容分发网络）的作用：加速访问、保护/隐藏真实 IP。
  • 绕过手段：
    • 查看历史 DNS 记录（如 SecurityTrails、DNSdb）。
    • 全球 Ping 测试，寻找未使用 CDN 的节点。
    • 通过 SSL 证书比对。
    • 通过邮件服务器（发信源 IP 大概率是真实 IP）。
    • 敏感信息泄露（如 phpinfo、探针文件）。
  • 实战意义：如果目标套了 CDN，你直接打域名只是在打 CDN 节点，完全无效。必须找到真实 IP 才能发起实质攻击。

5. 旁站查询

  • 概念：同 IP 下的其他网站（即“旁站”）。
  • 思路：如果主站打不进，可以寻找同服务器上防御薄弱的小网站下手，通过拿下旁站，利用服务器内部权限进行横向移动，最终拿下主站。

三、 目录收集

寻找敏感文件泄露，这是最容易出成果的一步。

1. 网站主动暴露

  • robots.txt：爬虫协议，常暴露后台路径或隐藏接口。
  • sitemap.xml：网站地图，了解站点结构。

2. 敏感文件泄露

  • 备份文件：www.zip、web.tar、www.rar 等。
    • 致命点：开发人员安全意识差，将源码打包上传到 Web 根目录，下载后直接白盒审计。
  • 版本控制泄露：.git/、.svn/ 目录。
    • 常用工具：GitHack、dvcs-ripper，直接还原源码。
  • 配置文件：.env、config.php、web.config 等。
    • 致命点：直接泄露数据库账密、云服务 AK/SK，导致服务器沦陷。

3. 目录爆破（依赖字典爆破）

  • 原理：利用常见目录/文件名字典，去猜测网站隐藏路径。
  • 常用工具：dirsearch、gobuster、feroxbuster。
  • 核心：字典的质量决定了爆破的成功率。

🛠️ 渗透信息收集常用工具箱

  • 网络空间测绘：Fofa、Shodan、Quake、Hunter
  • 指纹识别：Wappalyzer（浏览器插件）、whatweb（命令行）
  • 端口扫描：Nmap、Masscan
  • 子域名/目录扫描：OneForAll、dirsearch、gobuster
  • 抓包/改包：Burp Suite、Yakit
